# SEO prerender snapshot contract

The local snapshot source is a JSON export of public data only. No snapshot is committed or generated by the prerender process.

## Root structure

- `metadata`: required provenance object.
- `categories`: non-empty array of public categories used by SSG and category routes.
- `ads`: array of ads eligible for public indexing.
- `categorySsgDataBySlug`: object containing one complete SSG payload for every category slug.

`metadata` requires:

- `source`: export mechanism or authorized export identifier.
- `sourceDatabase`: source database name, without connection details.
- `exportedAt`: ISO date-time string.
- `schemaVersion`: currently `1`.
- `siteBaseUrl`: optional HTTPS site base; when supplied, it must match the configured public site URL.

## Public category fields

Every category requires `_id` (24-character ObjectId), `slug`, `name`, `description` (may be empty), `image` (string or null), and `children` (array of categories with the same shape).

Each `categorySsgDataBySlug[slug]` requires:

- `category`: the matching category object.
- `breadcrumbs`: array of `{ name, slug }` entries.
- `subcategories`: array of public category objects.
- `ads`: array of complete, currently indexable public ads belonging to that category.

## Public ad fields

Each ad requires `_id`, `slug`, `title`, `description`, `status`, boolean `isDeleted`, `isVisible`, and `isArchived`, a boolean `sold` or `isSold`, a valid future `expiresAt`, `adType` (`sell` or `order`), finite non-negative numeric `price`, `currency`, boolean `priceOnContact`, `images` (array of public image path strings), and `categoryId` containing `_id`, `slug`, and `name`.

`governorateId` and `cityId` may be null or public objects containing only a display `name`. Optional availability or inventory fields must retain their source types and must not contradict public availability.

The validator rejects non-indexable ads, duplicate IDs/slugs, incomplete category SSG payloads, invalid ObjectIds, and known private fields. Exporters should include only fields required for public pages; do not include account records, contact details, credentials, tokens, sessions, payment data, or private document paths.

## Source selection and freshness

- `SEO_PRERENDER_DATA_SOURCE=local` selects the snapshot and never falls back to the API or seed data.
- `SEO_PRERENDER_SNAPSHOT_PATH` optionally selects its file; otherwise the expected path is `frontend/data/seo-prerender-snapshot.json`.
- `SEO_PRERENDER_MAX_AGE_MS` optionally enables a maximum age in milliseconds. When unset, no freshness limit is claimed.
- Without `SEO_PRERENDER_DATA_SOURCE=local`, the existing API source remains selected.

An absent, invalid, stale (when a maximum age is configured), or incomplete snapshot must fail before page generation. Generate and validate an authorized local export separately before selecting local mode.
